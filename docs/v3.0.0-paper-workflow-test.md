# v3.0.0 RC003 组卷流程测试记录

## 覆盖范围

RC003 将组卷流程整理为：选择资料 → 试卷设置 → 分阶段生成 → 独立编辑 → 学生/教师预览 → 保存、导出或开始答题。

## 已验证能力

- 单份和多份资料选择，并显示已选数量与字符数。
- 快速小测、课堂练习、单元测试、错题强化等系统模板。
- 自定义模板保存、重命名和删除；系统模板不可删除。
- 试卷名称、时长、题量、总分、题型数量/分值和难度比例配置。
- 题型数量、总分及难度比例实时校验，支持自动补齐与自动调整。
- 图表、听力及当前 AI 服务模式设置。
- 阶段式生成提示，不伪造精确百分比。
- 独立试卷编辑器：编辑、移动、拖拽排序、复制、删除、锁定、待检查、单题重新生成。
- 轻量重复题检测仅提示，不自动删除。
- 学生版和教师版预览，以及现有 PDF/答案/听力音频导出入口。
- 编辑器可直接“开始答题”。
- 设置与编辑草稿自动保存、恢复；重新开始和删除草稿均需二次确认。
- 草稿模型不包含 API Key、JWT、支付密钥或完整请求头。
