# AI题库 v3.0.0 RC006：Card Run 规格

## 产品定位

Card Run 是“随机学习局”，与普通练习和章节闯关相互独立：

- 普通练习：直接完成一组题；
- 闯关模式：推进章节地图；
- Card Run：从本地题库进行一局带卡牌选择与增益的学习。

## 第一版流程

默认最多 10 题：

```text
三选一 → 3 题 → 三选一 → 3 题 → 三选一 → 4 题 → 结算
```

题库不足时只提供“缩短本局”或“前往生成更多题目”。Card Run 本身不会偷偷调用 AI；只有用户明确前往出题流程后，模型请求才可能发生，并继续由 AI Cost Guard 保护。

## 卡池

首版共 15 张程序化卡牌，分为五类：

- REVIEW：再战、薄弱突袭、重返现场；
- BOOST：双倍成长、黄金 5 分钟、稳定成长；
- CHALLENGE：精准猎手、无伤挑战、越级挑战；
- SUPPORT：学习护盾、再试一次、重抽；
- EVENT：知识宝箱、隐藏 Boss、神秘卡。

类型与稀有度独立，稀有度使用“普通、少见、稀有、特殊”，不采用赌博式 R/SR/SSR 命名。

## 数据真实性

- 全局 XP 共享，但来源记录为 `CARD_RUN_BASE` 与 `CARD_RUN_BONUS`；
- 增益使用“基础 XP + Bonus”，不做指数乘法；
- 普通题的卡牌 Bonus 上限不超过基础 XP 的 100%；
- 护盾只保护本局连胜，不会把真实错题改成正确；
- “再试一次”保留第一次错误，并额外标记 `corrected=true`；
- Card Run 增益不进入章节闯关，闯关增益也不进入 Card Run；
- 一局只结算一次。

## 视觉与无障碍

卡面由 Flutter 组件、图标、渐变与动画程序化绘制，不引入大型视频、GIF 或 PNG 序列。五类卡牌具有独立视觉语言。开启“减少动态效果”后，3D/飞入类动作降级为淡入和状态变化，全部功能仍可使用。

## 自动化覆盖

- 15 张卡与五种类型齐全；
- 无历史错题时不出现不可用 REVIEW 卡；
- 三选一节点为 0/3/6；
- XP 加法与上限；
- 护盾不篡改真实结果；
- 再试一次保留首次错误；
- 一整局本地 UI 只结算一次；
- 默认流程不触发模型调用。

## 后续可扩展项

- Boss 专属事件；
- 更完整的英文界面；
