# AI题库 Android v3.0.0 RC004 Test002

> 内部预发布测试版，不会真实扣款，不替换官网当前稳定版。

## 本轮重点修复

### 1. 修复“生成 10 道题却只得到 1 道”

- 普通练习与试卷改为最多 5 道一批的分批生成，降低长 JSON 被模型截断的概率。
- 每批结果会校验、合并和去重，直到达到用户选择的准确题量。
- 支持挽救模型已经返回的完整 JSON 对象，再继续补齐剩余题目。
- 如果自动补齐后仍不足，不再把残缺的 1 道题当成成功结果进入答题页；应用会给出中文提示并允许重试。
- 闯关小游戏继续保留原有本地安全补题机制，模型偶发少返回时不会阻断关卡。

### 2. 改善模型返回不完整问题

- 每批请求增加严格 JSON 指令，禁止 Markdown、说明文字和省略号。
- 限制单批题量，并要求题干、答案及必要字段完整。
- 后续批次会避开已经生成的题目，减少重复内容。
- 对单个完整对象、根对象数组和末尾截断响应进行兼容解析。
- 错误提示不再直接显示难懂的 `FormatException` 英文堆栈。

### 3. 修复深色模式文字不可见

- 修复“问题反馈”弹窗的标题、说明、反馈类型按钮、输入框和收件邮箱颜色。
- 修复答题页题型标签、题干、文本答案输入框在深色模式下的对比度。
- 修复答题结果区域的背景、边框、用户答案、参考答案和解析文字。
- 统一输入框与选择标签的主题颜色，减少白底白字、深底深字问题。
