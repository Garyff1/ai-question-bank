# RC005 秘密信息审计

日期：2026-08-08
范围：Git tracked files

## 审计原则

扫描 API Key 形态、Authorization、Bearer、`API_KEY`、`SECRET`、`PRIVATE_KEY`、历史微信/支付宝配置和旧官方 Token 标识。报告只记录文件与类别，不复制任何疑似秘密值。

## 结果

- 未发现提交到 Git 跟踪文件中的真实第三方 API Key。
- 未发现真实微信或支付宝私钥、证书、商户密钥。
- `.env.example` 只保留环境变量名称和占位说明。
- 源码中的 `Authorization: Bearer` 为运行时请求头构造，不包含硬编码凭证。
- 测试中的 Key/Token 为明显的本地占位值。
- 历史官方 Token 键名只用于 RC005 一次性迁移清理。
- Release APK 静态扫描未发现硬编码第三方 Key、JWT、Cloudflare Tunnel 令牌、官方 AI 路由或真实支付功能开关。
- APK 中 Apache Tika MIME 数据库带有识别 PEM 私钥文件头的规则文本；它不是私钥内容，已作为已知误报记录。
- Git 历史可能包含已经停止的商业实验结构；任何曾经真实使用过的外部密钥仍应在服务商后台轮换，不能依赖仓库扫描作为唯一保证。

## 持续要求

- 不在日志、截图、Issue、诊断报告和 Motion Lab 中输出 Key。
- 不把 Key 写入普通 SharedPreferences、备份、试卷或学习记录。
- 发布前再次扫描 Git tracked files 和构建产物。
