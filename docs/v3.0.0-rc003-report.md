## 本轮完成内容

### AI 服务模式

- 生成、组卷和 API 配置页展示当前服务模式，可直接打开底部面板切换。
- 自带 API Key 与官方 AI 服务切换不会删除服务商、Key、Base URL、模型、资料或组卷配置。
- 自带 Key 未配置时在请求前给出引导；官方服务保留内部测试提示，真实支付关闭。

### 组卷与编辑

- 支持多资料组卷、常用模板和本地自定义模板。
- 增加试卷名称、时长、题量、总分、题型数量/分值及难度比例校验。
- 生成过程使用真实阶段提示，完成后进入独立编辑器。
- 编辑器支持逐题编辑、排序、复制、删除、锁定、待检查、单题重新生成及重复题提醒。
- 支持学生版/教师版预览、保存、导出和直接开始答题。
- 设置与编辑草稿自动保存；继续、重新开始、删除路径完整，危险操作二次确认。

### API Key 安全

- 默认遮挡、短时显示、后台/锁屏/离页自动隐藏。
- 配置页启用系统防截屏；Android 应用备份关闭。
- 不提供复制完整 Key 的按钮。
- 日志与用户错误信息统一脱敏；Debug 构建提供不显示完整 Key 的安全自检。

## 数据与兼容

- 继续兼容既有资料、题目、错题、XP、闯关和 API 配置。
- 新增服务模式、组卷模板和草稿使用独立本地键。
- 草稿不保存 API Key、JWT、支付密钥或请求 Header。
