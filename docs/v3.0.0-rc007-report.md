# AI题库 v3.0.0 RC007 报告

## 基线

- 分支：`codex/v3-rc007-security-interaction`
- 基线提交：`921999cd1ac3cbd800d139d2829d6e4975dc5d8d`
- 版本：`3.0.0+64`
- 产品方向：Local-first、BYOK-only；无官方 AI 云服务和真实支付。

## 本轮目标

RC007 不是继续堆叠大型玩法，而是先让现有代码与发布链路更平稳，同时在首页补充适量、可降级的互动反馈：

1. 建立稳定 Android Release 签名链路。
2. 加固 FastAPI 配置、密钥、上传、登录、SSRF、静态文件和数据库行为。
3. 加固 Tauri sidecar 生命周期与 Web 功能页的数据边界。
4. 优化首页信息层级、按压反馈、状态动画和深色主题表现。
5. 保持 RC006 的资料、题目、错题、XP、闯关、Card Run、OCR、TTS 与试卷数据兼容。

## 互动与 UI 优化

- 首页头部加入低成本环境动效，使用位移和透明度，不引入视频、GIF 或大型图片资源。
- 开启“减少动态效果”后，环境层自动变为静态，主要操作仍可正常使用。
- 今日任务卡增加轻按压、位移和完成状态切换反馈。
- “继续挑战”卡加强路径感、状态层级和可点击提示。
- 快捷入口卡使用轻微主题色渐变、装饰光斑和方向提示，减少纯平面堆叠感。
- 首页状态数字变化使用统一过渡，并修复窄屏文字溢出。
- 学习状态区域移除写死浅色背景，改善深色模式可读性。
- `_BouncyTap` 增加语义标签、禁用状态和小幅纵向按压反馈。

这些改动遵循“互动可感知、内容仍优先、低端设备可降级”的原则，没有改动题目生成、API Cost Guard、支付边界或统计真实性。

## 安全与可靠性

详细内容见 [RC007 安全加固说明](v3.0.0-rc007-security-hardening.md)。主要完成：

- Android 稳定签名与 GitHub Secrets；
- API Key 数据库加密和历史明文迁移；
- CORS、SSRF、路径穿越和 XSS 防护；
- 登录限流、上传边界与数据库并发设置；
- Tauri CSP 和精确 sidecar 进程回收；
- 生产环境密钥缺失时安全失败。

## 数据兼容

- Android 本地存储字段没有改名或删除。
- BYOK API Key 的 Android Keystore 结构没有回退。
- 后端旧明文 API Key 在成功加密并回读后才完成迁移。
- 资料、题库、错题、历史、XP、打卡、闯关与 Card Run 数据结构保持兼容。

## APK 与预发布

最终 APK 大小、SHA-256、签名证书摘要和 GitHub Pre-release 地址将在云端签名构建完成后补记。

## 已知问题与后续工作

- `main.dart` 仍然较大。本轮只新增独立 Widget，没有为重构而重写稳定页面；后续应按功能逐步迁移。
- 当前 Web 页面仍包含较多内联脚本和样式，因此 CSP 暂时保留 `unsafe-inline`；动态内容已先完成转义，后续再拆分静态资源以进一步收紧策略。
- 桌面模式的本机加密密钥与用户数据同属用户目录，主要防止数据库文件被单独复制后直接读取；正式联网部署必须使用独立环境密钥管理。
- Syncfusion 许可和真实真机总回归继续属于正式公开发布阻断项。
- 本轮不合并 `main`、不更新官网、不覆盖 v2.9.9 正式下载。
