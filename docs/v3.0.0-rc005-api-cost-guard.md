# RC005 AI Cost Guard 设计

## 目标

保护用户自己的第三方模型额度，防止快速重复点击、异常重试链、取消后继续请求和页面销毁后的迟到结果覆盖。

## 核心规则

1. 全局同一时间只允许一个活动 AI Task。
2. 每个 Task 具有随机 `taskId`、匿名请求指纹、目标题数和状态。
3. 三秒内相同指纹被拦截；正常任务完成后用户仍可主动再次生成。
4. 每分钟创建任务达到异常阈值后开启本地 Circuit Breaker。
5. 单个任务请求链具有动态安全上限，绝不允许无限修复请求。
6. 自动重试最多一次。
7. 401、403、429、Key 无效、余额不足、模型不存在和参数错误不进行无限重试。
8. 临时网络错误、TLS 瞬时错误和服务商 5xx 最多重试一次。
9. 用户取消会关闭当前 HTTP Client、停止后续重试，并阻止迟到结果被接受。
10. 大任务和每日任务达到提醒阈值时显示额度提示，不伪造人民币费用。

## 本地记录

最多保存 200 条脱敏记录：

- Task ID
- 时间
- 任务类型
- 服务商和模型
- 目标题数
- 请求次数和自动重试次数
- 成功、失败、取消或拦截状态
- 服务商提供时的输入/输出 Token
- 脱敏错误分类

绝不记录 API Key、Authorization Header、完整 Prompt、完整资料正文、密码或 JWT。

该记录不等于服务商账单，最终用量和费用以服务商控制台为准。

## 用户设置

- 自动重试：默认开启，最多一次。
- 大任务提醒：默认开启。
- 普通 AI 操作确认：默认开启。
- 显示本机调用记录：默认开启。
- 每日任务提醒阈值：10、20、40 或 80 次。
- 熔断后由用户检查记录并手动恢复。
