# AI题库 Android v3.0.0 RC004 Test003

> 内部测试版本，不会产生真实扣款；官网正式下载仍保持原有稳定版本。

## 本次重点优化

### 1. 出题更贴合资料核心内容

- 新增统一的“资料锚定出题规范”，普通练习、闯关、小游戏和试卷共同遵守。
- 优先围绕教材的核心概念、原理、方法、公式、实验与典型应用出题。
- 每道题要求返回具体知识点和资料依据，减少脱离资料、仅凭常识生成的题目。
- 图表题只允许表达专业数据、变量关系或实验结果。
- 禁止将章节数量、习题数量、页数、字数等文档元数据作为考点。
- 本地增加无关元数据题拦截；命中后不会进入题库，而会继续补题。

### 2. 修复大题量试卷生成不完整

- 分批生成会根据模型实际返回能力自动调整批次。
- 即使模型每次只能完整返回 1 道题，也会继续请求直至补齐目标数量或确认服务商无法完成。
- 试卷单批上限收紧为 3 道，降低长 JSON 被截断的概率。
- 增加重复题、无效题和无关元数据题过滤。
- 不再把“请求 20 道、收到 6 道”误认为生成成功。

### 3. 练习详情更清楚

- 修复深色模式下题型名称、数量和进度底色不可读的问题。
- “错题知识点诊断”精简为本次练习的核心错题知识点摘要。
- 按错题数量显示前 5 个优先巩固项，并展示本次主要考察内容。

### 4. 修复闯关深色模式题干不可见

- 闯关顶部关卡名、题型说明、题干和操作提示改为主题自适应颜色。
- 排序、配对、听力、闪卡、快选、拼写、填空、判断和连连看题面同步适配。

## 测试提示

建议重点验证：

1. 机器人、数学、物理等资料生成的题目是否真正围绕教材知识。
2. 开启图表后是否还会出现“各章节习题数量”一类题目。
3. 生成 10 道普通题及 20 道试卷时是否严格返回完整题量。
4. 深色模式下练习详情和全部闯关题面是否清晰可读。
5. 旧资料、错题、XP、API 配置和闯关记录是否保留。
