## 主要更新

- 按学科控制图表、公式与英语听力能力；
- 英语听力改用独立听力脚本，避免直接朗读答案或解析；
- 试卷生成改为真实小批次、部分成功保留与安全补齐；
- 增加生成诊断，定位模型返回、JSON、校验、过滤与去重阶段；
- 修复闯关闪卡镜像、答案交互和窄屏 Boss 溢出；
- 新增闯关暂停、返回键与后台自动暂停；
- 新增 Card Run 本地卡牌学习模式，15 张卡、五种类型；
- Card Run 默认不调用 AI，XP 增益不篡改真实答题统计；
- 首次引导完整适配浅色、深色与系统主题；
- 调整 GitHub Actions，普通 main push 不再自动发布正式版本；
- `local.properties` 不再进入 Git。
