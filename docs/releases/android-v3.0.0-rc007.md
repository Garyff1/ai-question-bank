# AI题库 Android v3.0.0 RC007（测试版）

本版本为 GitHub Pre-release，用于安全加固与交互体验验证，不会替换官网 v2.9.9 正式下载。

## 主要更新

- 首页增加轻量环境动效、按压反馈、状态切换和更清晰的学习路径层级；
- “减少动态效果”可将新增动效安全降级为静态展示；
- 修复首页深色模式状态卡和窄屏文字溢出；
- Android Release 改用稳定签名，构建缺少正式签名时会安全失败；
- GitHub 发布前使用 Android 官方工具强制验签，并同时提供 SHA-256 校验文件；
- 后端 API Key 加密保存，并兼容迁移历史配置；
- 加固 CORS、SSRF、目录穿越、HTML 注入、登录爆破和文件上传边界；
- SQLite 增加外键、WAL、忙等待和事务回滚；
- Tauri 只关闭当前桌面壳启动的内置后端，不再误杀同名进程；
- Tauri 增加 CSP，Web 功能页限制 API 地址并转义动态内容；
- 升级后端安全相关依赖并补充 12 项专项测试。

## 验证

- Flutter Analyze：0 错误、0 警告；
- Flutter 测试：133 项通过；
- Backend 测试：17 项通过；
- Tauri `cargo check`：通过；
- 最终 APK 由 GitHub Actions 使用稳定签名构建。

## 安装提示

RC006 及更早的部分测试包使用了不同的 debug 签名。如果 Android 提示“无法安装”或“签名不一致”，请先卸载旧测试包，再安装 RC007。请先确认重要本地资料已有备份。

## 安全边界

- 继续采用 BYOK-only；
- 不包含官方 AI 云服务、作者 API Key 或真实支付；
- 不合并 `main`，不更新官网正式下载；
- OCR/TTS/旧 MP3、持续性能和多机型仍需真机验收。
