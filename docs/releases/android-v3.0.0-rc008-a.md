# AI题库 Android v3.0.0 RC008-A（测试版）

本版本集中修复“题目生成不完整、混合卷题型不符合配置、长资料后半部分无法被使用”等核心问题。

- 版本：`3.0.0+65`
- 类型：GitHub Pre-release
- 正式官网：仍保持 v2.9.9，不受本测试版影响

## 主要更新

- 试卷改为逐批保存：后续批次超时或失败时，前面已经生成的有效题目不会丢失。
- 用户取消生成前，会先等待最新有效批次写入本地草稿；不会继续发起自动请求。
- 继续补题只补缺失题型，并继续受 API 调用保护和请求上限约束。
- 混合卷按单选、多选、填空、判断、解答的实际配额逐批生成。
- 超出配额、未知题型、缺选项或答案结构错误的对象不再被误计为完成。
- 修复多选题在提示词、章节、答案结构和完成判断中的规则冲突。
- 长资料不再只读取开头：会覆盖开头、中部、结尾及指定章节/知识点附近内容。
- 单题重新生成的用户要求改为最高优先级指令，不会因原资料过长而被截掉。
- 部分成功提示新增缺失题型和逐层诊断，方便判断问题发生在模型返回、结构校验、重复过滤还是题型配额。
- 单个异常对象不会拖垮整份已经生成的试卷。

## 测试建议

建议重点测试：

1. 生成包含五种题型的混合试卷。
2. 生成过程中断网，确认已完成题目仍在试卷草稿中。
3. 生成过程中点击取消，再进入试卷页查看草稿。
4. 对超过 10000 字的资料指定后半部分知识点出题。
5. 对长资料中的单题使用“只改数值”或“改为指定题型”重新生成。

真实模型输出存在差异。如果只生成部分题目，请先保留草稿，再根据缺失题型选择“继续补齐”；继续操作会再次调用你自己的模型 API。
