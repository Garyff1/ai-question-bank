# AI题库 v3.0.0 RC007 安全加固说明

RC007 在不改变 BYOK-only 产品方向的前提下，集中关闭后端、桌面壳、Web 功能页和 Android 发布链路中的高风险问题。

## Android 发布签名

- Release 构建不再默认使用 Android debug key。
- 构建脚本从本地 `key.properties` 或受保护的 CI 环境变量读取签名配置。
- 缺少正式签名时，Release 构建会主动失败；仅内部 CI 可以通过显式开关生成调试签名测试包。
- CI 和预发布流程使用 Android 官方 `apksigner` 强制验签，并随 APK 生成 SHA-256 文件。
- 稳定签名文件保存在仓库之外，GitHub Actions 仅通过加密 Secrets 使用。
- 签名文件、口令和 Base64 内容不得进入 Git、日志、Issue、APK 静态资源或项目文档。

### 升级注意事项

RC006 及更早的部分测试包使用了不同的 debug 签名。首次安装 RC007 稳定签名包时，Android 可能拒绝覆盖安装，需要先卸载旧测试包。RC007 之后必须持续保存并使用同一签名身份，避免再次中断升级链路。

## 后端

- 默认只监听 `127.0.0.1`；非桌面网络部署必须显式配置监听地址。
- 生产模式缺少 JWT 或数据加密密钥时拒绝启动；开发/桌面模式生成并持久化本机密钥。
- 用户模型 API Key 使用 Fernet 加密后写入数据库，并兼容迁移历史明文配置。
- CORS 改为显式白名单/正则配置，移除任意来源携带凭证访问。
- 静态文件返回使用规范化路径校验，阻止目录穿越；不存在的 `/api/*` 不再回退到首页。
- 自定义 API Base URL 在保存和请求前校验，阻止本机、内网、链路本地、保留地址和危险重定向，降低 SSRF 风险。
- 登录增加本机失败次数限制；注册邮箱归一化并要求至少 10 位密码。
- SQLite 启用外键、WAL 和 busy timeout；事务异常自动回滚。
- 上传改为分块限流，并同时检查扩展名和文件魔数。
- 对外错误提示不再直接包含内部异常、请求头或服务商敏感细节。

依赖同步升级了 `python-jose`、`python-multipart`、`httpx` 与 `cryptography`，关闭已知旧版本风险。

## Tauri 与 Web 功能页

- Tauri 新增内容安全策略，只允许本地资源、IPC 和桌面壳注入的本机后端端口。
- 关闭桌面程序时只终止当前壳保存的 sidecar 子进程，不再按进程名强制结束系统内所有 `backend.exe`。
- Web 功能页只接受同源、本地开发地址或 Tauri 注入的 `127.0.0.1` 动态端口作为 API Base。
- 历史保存的危险 API Base 会被清除。
- 服务端返回内容写入 HTML 前统一转义，减少持久型或反射型脚本注入风险。

- Phase 2 Test002 的真实手写、多页 OCR、真实扬声器/耳机 TTS 和旧 MP3 导出仍需真机验收。
- 深浅色、中英文、持续内存、发热和 2—3 部设备覆盖升级仍需统一真机回归。
- 隐私、BYOK 数据流和中国大陆生成式 AI 应用合规事项仍需独立审核。
