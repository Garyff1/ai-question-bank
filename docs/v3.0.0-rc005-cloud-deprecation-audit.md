# RC005 官方云服务退役审计

状态：已完成代码依赖审计与产品路线收敛
日期：2026-08-08

## 结论

Phase 3 的官方 AI、报价、订单、支付和退款代码位于独立的 `backend/app/official_ai/` 模块，并只通过 `backend/app/app.py` 注册。Android 对应入口位于 `features/official_ai/` 和 `features/service_mode/`。这些模块不属于网页经典版、普通认证、资料、出题、练习、统计或桌面端内置后端的必要依赖。

因此 RC005 已从当前产品代码中移除这些商业实验模块，Git 历史继续保留全部实现。

## 客户端处理

| 范围 | 原用途 | RC005处理 |
| --- | --- | --- |
| `features/official_ai/` | 官方账户、报价、订单、支付与法律草案 | 删除活动代码 |
| `features/service_mode/` | BYOK/官方服务双模式 | 删除，改为 Provider Portal |
| 官方 Token | 官方服务登录凭证 | 首次启动安全删除 |
| `ai_service_mode_v3` | 旧双模式选择 | 迁移后删除 |
| `official_ai_base_url_v3` | 旧官方服务地址 | 迁移后删除 |
| 用户 API Key | 用户自己的模型凭证 | 保留并校验不变 |
| 试卷 `serviceMode` 字段 | 历史 JSON 兼容 | 只写 `byok`，保留可选字段避免旧数据破坏 |

## 后端处理

已移除：

- `backend/app/official_ai/`
- 官方 AI 数据模型注册和迁移
- `/api/official-ai/*` 路由
- 微信、支付宝、Mock 支付、报价、订单、退款和影子计费配置
- 对应 Phase 3 商业实验测试

继续保留：

- `/health`、`/api/status`
- `/api/auth/*`
- `/api/materials/*`
- `/api/questions/*`
- `/api/practice/*`
- `/api/stats`
- `/api/config/*`
- 静态官网和桌面端既有 FastAPI 能力

自动化测试会检查 OpenAPI 中不存在 `/api/official-ai`，同时验证认证、资料和服务商模板接口仍然可用。
