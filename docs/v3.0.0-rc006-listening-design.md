# AI题库 v3.0.0 RC006：英语听力设计

## 设计目标

听力题不再是“把普通题干直接用 TTS 朗读”。RC006 将用户听到的内容与屏幕上看到的问题分离，同时限制听力能力只在适合的学科中出现。

## 数据结构

听力题新增可选字段：

```text
listeningScript       用户实际听到的自然英语
question              用户在屏幕上看到的问题
options               可选择答案
answer                正确答案
explanation           解析
listeningVoiceLocale  建议语音区域，例如 en-US
```

旧题没有 `listeningScript` 时继续使用兼容回退，不破坏历史数据。

## 生成规范

- 只在英语或 Custom 明确开启时生成；
- 闯关模式本轮禁用听力题，避免无音频环境阻断关卡；
- 脚本使用自然英语，不包含 Markdown、JSON 标记、答案或解析；
- 自动清理代码围栏、标题符号和不适合朗读的结构字符；
- 对话与短文优先，避免直接朗读 A/B/C/D 的技术结构；
- 可见问题、选项与听力文本相互独立。

## 播放与降级

当前统一播放层支持播放、暂停、继续、停止和重播，并对语言区域进行归一化。系统缺少英语语音或 TTS 失败时：

1. 保留题目与文字内容；
2. 显示可理解的失败提示；
3. 允许重试音频；
4. 不重新调用 AI 重写题目；
5. 不阻塞整张试卷保存。

## 学科能力

- English：默认允许听力；
- Custom：允许用户覆盖；
- 语文、数学、物理、化学、生物、地理、历史、政治：默认隐藏听力入口；
- 能力规则集中在 `SubjectCapabilities`，不在页面中重复硬编码。

## 自动化覆盖

- 新结构解析；
- 旧结构兼容；
- 脚本不会直接泄露答案；
- Markdown/JSON 标记清理；
- 英语与非英语学科能力；
- 播放服务的暂停、停止与重播状态。

## 人工真机待测

自动化测试不能证明声音“听起来自然”。以下项目仍标记为 Pending：

- 英文短对话与短文试听；
- 人名、日期、数字与缩写；
- 中英文混读；
- 扬声器、蓝牙/有线耳机；
- 三档语速与两次播放体验；
- 音频焦点被其他应用打断；
- 旧试卷 MP3 的实际导出和系统播放器完整播放。
