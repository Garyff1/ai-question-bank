# AI题库 v3.0.0 RC005 开发报告

## 阶段结论

- 主题：BYOK-only 架构收敛与 API 使用保护
- 分支：`codex/v3-rc005-byok-service-assurance`
- 版本：`3.0.0+62`
- 基准：RC004 Test003 `42708fa`
- 状态：开发、自动化验证与 Release APK 构建完成；真机验收 Pending
- 正式发布：关闭

## 已完成

1. Android 正式客户端移除官方 AI、报价、订单、支付和退款入口。
2. RC004 模式传送门改为模型服务商 Provider Portal。
3. 支持 DeepSeek、Qwen、智谱、硅基流动、MiMo、Kimi 和自定义接口。
4. 按 2026-08-08 官方文档更新默认 Base URL、模型和 MiMo/Kimi 请求参数兼容。
5. 旧官方模式首次启动迁移到 BYOK，只清理官方 Token/prefs，不删除用户 Key。
6. 新增 AI Cost Guard：Task、指纹、防重、有限重试、取消、请求链上限和本地熔断。
7. 新增本机 API 使用记录、每日提醒阈值、脱敏凭证复制和手动恢复。
8. 大任务和单题 AI 重生成前提示可能产生新的第三方额度消耗。
9. 新增 BYOK 数据流、AI 内容、额度风险和异常调用说明页。
10. 移除隔离的 FastAPI 官方 AI 商业模块，保留普通网页/桌面端 API。
11. 更新 README、Issue 模板和历史文档状态。

## 数据兼容

- 资料、试卷、练习、错题、XP、打卡、闯关、主题和语言字段不改名。
- 用户 API Key 继续使用 Android Keystore 对应安全存储。
- 旧 `serviceMode` 字段只为读取历史试卷而保留；新数据固定写 `byok`。
- 迁移失败不会清空整个 Secure Storage。

## 安全边界

- 本机使用记录不保存 API Key、Authorization、完整 Prompt 或完整资料。
- 诊断报告只包含版本、Task、服务商、模型、次数、状态和脱敏错误分类。
- Release 不存在官方 AI 或支付入口。
- Backend OpenAPI 不存在 `/api/official-ai/*`。
