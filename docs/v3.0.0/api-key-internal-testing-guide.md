# API Key 内部测试指南（v3.0.0 RC003）

本指南用于开发者在 2—3 部自有 Android 手机上验证“自带 API Key”模式。RC003 是内部测试版，不包含开发者个人 API Key，也不开放真实支付。

## 测试前准备

1. 为测试单独创建低额度、可随时撤销的 API Key，不使用主账号长期 Key。
2. 在服务商后台设置调用额度或预算告警，并记录 Key 创建时间。
3. 不通过聊天、邮件、截图、录屏或公开 Issue 传递完整 Key。
4. 安装前记录手机品牌、型号、Android/API 版本、内存、CPU ABI、默认 TTS 引擎及是否支持 Google 服务；序列号只记录脱敏值。
5. 确认测试包 SHA-256 与发布页一致。

## 每台手机的测试步骤

1. 从 RC002 覆盖安装 RC003，确认资料、错题、XP、闯关进度和设置未丢失。
2. 进入“生成”或“试卷”页，点击顶部“当前服务”，在自带 Key 与官方服务间切换。
3. 切换模式后确认原服务商、Base URL、模型名和 Key 均未被删除。
4. 自带 Key 未配置时，确认在请求前出现配置引导。
5. 在 API 配置页粘贴测试 Key：默认应隐藏，仅短时允许查看；切后台、锁屏或离开页面后必须自动恢复隐藏。
6. 保存并重启 App，确认 Key 可使用，但普通设置、导出文件和备份中不存在明文 Key。
7. 测试连接成功与失败提示，确认错误信息不包含 Authorization、Bearer 或完整 Key。
8. 删除配置后重启，确认安全存储中的 Key 已清除。
9. 检查 `adb logcat`、截图、测试报告和 Git 工作区，确认没有完整 Key。
10. 完成普通出题、组卷、单题重新生成、学生/教师预览和 PDF 导出。

## 测试结束后

1. 在服务商后台核对调用量与异常请求。
2. 轮换或删除测试 Key。
3. 再次检查日志、截图、临时文件和 Git 状态。
4. 记录问题时只保留服务商、模型、HTTP 状态码和脱敏后的 Key 末四位。

## 通过标准

- Key 仅保存在 Android Keystore 支持的安全存储中。
- 默认遮挡，短时查看后自动隐藏，后台/锁屏立即隐藏。
- API 配置页受系统防截屏保护。
- App 备份被禁用，不提供复制完整 Key 的按钮。
- 日志和用户错误提示不会泄露完整 Key。
- 模式切换、官方账号登出不会删除用户自带 Key。
