# AI题库 v3 动效设计规范

> 原指令名称为 RC003；仓库中 `3.0.0+57` 已被既有 RC003 使用，因此本实现顺延为 **RC004 / 3.0.0+58**。本文档保留约定文件名，避免破坏交接索引。

## 1. 设计概念：Knowledge Forge

“知识炼成”把资料到练习的转换过程表现为可理解的阶段，而不是用装饰动画掩盖等待。所有动效必须服从真实业务状态，不能伪造题目数量、网络进度、订单状态或付款结果。

六个核心动词：

1. 扫描（Scan）：OCR 扫描镜沿资料移动，表达识别范围。
2. 提取（Extract）：资料中的知识节点从文本层浮现。
3. 聚合（Aggregate）：知识节点向中心知识核心汇聚。
4. 生成（Generate）：真实返回的题目形成卡片堆。
5. 排列（Arrange）：题目按题型、题号和分值重新排序。
6. 装订（Bind）：题目卡吸附为可预览、可打印的试卷页。

## 2. 动效 Token

| 场景 | 建议时长 | 说明 |
|---|---:|---|
| 微交互 | 120–180ms | 点击、选中、轻触反馈 |
| 选择切换 | 160–220ms | 模式卡、答案层、按钮状态 |
| 页面过渡 | 280–420ms | 普通页面与底部面板 |
| 共享元素 | 480–700ms | 服务模式卡到传送门 |
| 炼成与装订 | 650–950ms | 生成和试卷阶段叙事 |

曲线以 `easeOutCubic`、`easeInOutCubic` 为主；单次强视觉转场不超过 1000ms。颜色从 `ThemeData.colorScheme` 和语义颜色派生，不在业务页面散落硬编码。

## 3. 三个标志性转场

### 3.1 AI 服务模式传送门

- BYOK 与官方服务使用两张具有空间层级的卡片。
- 当前卡后退，目标卡前移，图标和标题通过共享元素进入当前服务区。
- 官方服务关闭时只显示测试/未开放状态，不触发订单或支付。
- 快速重复点击由控制器锁定，确认后不可再次改变本次结果。

### 3.2 知识炼成

- 状态顺序：读取资料 → 提取知识 → 规划题型 → 生成题目 → 检查结果。
- 阶段由业务状态驱动；真实题目尚未返回时不显示虚假逐题计数。
- 只有获得真实数量后才生成题目卡堆和 `已生成/总数` 信息。
- 失败和取消保留资料与草稿，并继续提供文字状态和返回操作。

### 3.3 试卷装订

- 题目按题型聚合、编排题号、分页、装订，再展开第一页。
- 多页通过轻量卡片堆表达，不对试卷正文使用大面积模糊。
- 排版失败时保留编辑内容，不创建空试卷。
- 学生版与教师版共享同一试卷正文，答案使用独立揭示层，不改变 PDF 数据。

## 4. 扩展交互

- 单题编辑：题目轻微抬起，背景试卷缩小；关闭时回到原位置。
- 单题重新生成：先比较原题与候选题，用户确认后才替换。
- 拖动排序：卡片抬升、轻微倾斜；松手后题号按真实顺序更新。
- OCR 扫描镜：只表示当前识别区域；识别结果仍由 OCR 服务提供。
- 答案层：学生版隐藏，教师版沿页面方向展开；减少动态效果时改为短淡入。

## 5. 降级策略

### 减少动态效果

- 取消大幅位移、旋转、透视和持续粒子。
- 保留 100–180ms 淡入或即时切换。
- 保留文字状态、取消按钮和所有操作结果。

### 低性能模式

- 禁止实时大面积模糊和持续粒子。
- 降低阴影层数，同时运动对象不超过 4 个。
- 复杂绘制改为静态渐变或简化卡片。
- 只降低视觉复杂度，不改变业务状态机。

## 6. 主题与无障碍

- 浅色模式使用浅灰蓝背景、白色卡片和科技蓝主色。
- 深色模式使用深蓝黑背景、深灰蓝卡片和高对比亮蓝/蓝紫主色。
- 不仅依赖颜色传递状态，同时使用图标、文字和语义标签。
- 核心状态使用 `Semantics(liveRegion: true)`；装饰元素不进入语义树。
- 支持中文、英文、系统字体放大和系统“减少动态效果”。

## 7. Motion Lab 边界

- 仅 Debug 或带 `INTERNAL_BUILD=true` 的内部构建显示入口。
- 只使用本地 Fake 数据，不读取资料、API Key、订单或支付状态。
- 可控制播放/暂停、重播、速度、主题、语言、减少动态和低性能模拟。
- 正式普通 Release 构建不显示入口。

## 8. 原创性与素材来源

本设计只参考 MotionSites 展示的通用设计方法：分层空间、共享元素、卡片运动、玻璃浮层和阶段叙事。所有 Flutter 组件、状态机、绘制和交互均为本项目独立实现；未复制 MotionSites 的付费提示词、商业素材、源代码或品牌资产，也不宣称与 MotionSites 存在合作关系。
