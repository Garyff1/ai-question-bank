## 3. Motion Lab

- 支持服务模式传送门、知识炼成、试卷装订、单题抬起、拖动排序、答案层和 OCR 扫描镜。
- 支持播放/暂停、重播、速度、浅色/深色、中文/英文、减少动态和低性能模拟。
- 数据来自 `MotionLabDemoData`，不含真实 API Key、资料、订单或价格。
- 入口条件：`kDebugMode || bool.fromEnvironment('INTERNAL_BUILD')`。

## 4. 业务接入

### 服务模式传送门

模式卡通过共享元素进入全屏传送门；确认后才返回新的服务模式。现有 API 配置和官方服务状态均由原控制器继续管理。

### 知识炼成

`GeneratePage` 将真实生成阶段传给 `KnowledgeForgeView`。在模型返回结果前只展示状态，不显示虚假逐题进度；真实结果到达后才显示题目数量。

### 试卷装订

试卷生成进度使用装订状态；进入预览前显示分组、编号、分页、装订和展开第一页。编辑器中的预览操作先完成短装订过渡，再打开原学生版/教师版预览。

### 单题编辑与重新生成

编辑弹窗使用抬起/缩放/淡入；减少动态时仅淡入。重新生成先显示原题与候选题比较，不再直接覆盖。

### 拖动排序与答案层

拖动卡片时增加抬升、轻微倾斜和可关闭的触觉反馈。教师版答案通过独立层揭示，学生版仍不显示答案。

### OCR 扫描镜

识别页提供扫描镜视觉和结果比较入口；视觉层不参与 OCR 结果判断，也不读写资料。
