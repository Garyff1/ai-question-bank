## 2. 本轮完成内容

### 核心可靠性

1. 建立统一学科能力规则，按学科显示图表、公式和听力功能。
2. 英语听力题拆分 `listeningScript` 与可见问题，兼容旧题。
3. 试卷采用 2—3 题的小批次与真实进度，支持部分成功、保留草稿和手动补齐。
4. 增加解析/过滤诊断，能够定位“目标 20 题但只保留少量题目”的丢失层级。
5. 补题与重试继续受 AI Cost Guard 限制，不引入无限模型调用。
6. 首次引导页完全跟随主题，避免浅色外壳与深色内容混用。
7. 修复 Flutter 3.47 对暂停面板 `ListTile` 材质层的严格断言，保持水波纹与背景正确绘制。

### 闯关体验

1. 修复闪卡翻面镜像与答案控件缺失。
2. 增加标准化 `questionOptions` 兼容字段。
3. 新增暂停/继续/重开/退出面板。
4. Android 返回键与切后台统一进入暂停状态。
5. 闯关本轮排除听力题，防止设备音频条件阻断关卡。
6. Boss 地图适配窄屏。

### Card Run

1. 新增本地 Card Run 学习模式。
2. 15 张卡牌、五种类型与四级稀有度。
3. 默认 10 题，0/3/6 进度节点三选一。
4. 使用本地错题和历史试卷，不自动发起 AI 请求。
5. XP 使用可审计的加法 Bonus，保留真实正确率和首次错误。
6. 支持减少动态效果和一次性安全结算。

### 仓库治理

1. 普通 push/PR 改为只运行 CI，不再自动创建正式 Release。
2. Android Release 只能通过手动工作流创建，且支持 Pre-release。
3. `android/local.properties` 不再被 Git 跟踪，保留开发机本地文件。
4. `.kotlin`、Gradle、CMake 与 Flutter 本地产物加入忽略规则。
