# AI题库 v3.0.0 RC006：闯关回归记录

## 本轮修复

### 1. 触摸与答案路径

逐项检查单选、多选、判断、填空、排序、配对与闪卡的交互层，避免透明覆盖层、动画容器或 `IgnorePointer` 截获答案点击。闪卡题新增标准化 `questionOptions`，翻卡后一定提供与题型匹配的作答路径。

### 2. 闪卡镜像

修正 `Matrix4.rotationY` 的正反面关系：卡片越过 90° 后对背面内容补偿 180°，并只保留当前可见一面参与绘制和触摸，避免镜像文字、透字及点击错层。

### 3. 暂停与生命周期

闯关页增加统一暂停层：

- 暂停/继续；
- 重新开始本关；
- 二次确认后退出；
- 暂停计时器、TTS、动画和自动推进；
- Android 返回键优先打开暂停层；
- 应用切入后台时自动暂停，返回后由用户主动继续；
- 退出不会重复结算 XP。

### 4. Boss 地图适配

章节地图在 320px 等窄屏上使用自适应尺寸与间距，Boss 节点不再被推到屏幕外。

### 5. 听力边界

本轮闯关生成明确排除听力题。普通出题和英语试卷仍保留听力能力，避免闯关因设备语音环境阻断。

## 自动化覆盖

- 五关/Boss 地图窄屏布局；
- 闪卡翻面后的非镜像可读文字；
- 闪卡选项可点击并更新状态；
- 暂停层阻止继续作答；
- 暂停后安全恢复；
- 背景生命周期自动暂停；
- 退出流程不重复结算。
