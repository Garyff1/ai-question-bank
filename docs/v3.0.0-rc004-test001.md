## 2. 本轮问题与修复

### P1：模型 JSON 截断导致生成失败

- 新增统一 `AiJsonParser`，支持 Markdown 代码块、根对象列表和截断响应中的完整对象抢救。
- 题目、试卷、闯关和小游戏统一接入“解析 → 抢救 → 仅补齐缺失数量”的有限重试流程。
- 对重复对象去重，避免重试产生重复题目。
- 原始 `FormatException / Unexpected end of input` 不再直接显示给用户，改为中文可操作提示。

### P1：部分题型无法作答

- 选择题、多选题支持从题干中提取 `A/B/C/D` 选项；仍无选项时安全降级为可输入的主观题。
- 判断题保证始终具有“正确/错误”选项。
- 排序题支持拖动排序，并支持从编号文本中提取排序项。
- 填空题、主观题以及无选项题统一提供文本输入框。
- 小游戏题型和选项经过归一化；不可作答的小游戏会被过滤并由既有回退题补齐。

### P1：窄屏 Boss 关卡溢出

- 章节节点改为按可用宽度平均分配五个关卡槽位。
- 连线、Boss 节点、锁定节点和底部状态条改为响应式布局。
- 新增 320px 窄屏回归测试，覆盖完整五关及 Boss，不再横向越界。

### P2：生成等待页静态且容易息屏

- “知识炼成”增加呼吸、轨道、光点和持续加载点动画，不伪造逐题进度。
- 支持“减少动态效果”和低性能降级。
- Android 原生增加生成期 `FLAG_KEEP_SCREEN_ON`，题目、试卷和闯关生成结束或失败后自动释放。
- 使用引用计数避免并发生成时过早清除常亮状态。

### P2：试卷更多设置在深色模式不可读

- 展开标题、图标、字段标签、说明文字、输入框、边框、图表与听力开关卡片全部改用主题色。
- 浅色和深色不再依赖写死的黑色/白色文字。
