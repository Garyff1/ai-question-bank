# AI题库 v3 RC004 动效性能报告

## 1. 性能目标

- 主流安卓真机核心转场接近 60fps。
- 不出现 Fatal Exception、ANR、OOM、Ticker 泄漏或持续无意义重绘。
- 生成动画可取消，页面销毁后控制器释放。
- 动效不影响 OCR、TTS、PDF、API 配置和订单状态。

## 2. 已实现控制

- `MotionPerformancePolicy` 将视觉分为完整、低性能、减少动态三档。
- 减少动态：关闭空间位移、旋转、粒子和模糊，最多 1 个运动对象。
- 低性能：关闭模糊和粒子，最多 4 个运动对象，阴影降为 1 层。
- 正常：最多 10 个轻量运动对象，阴影最多 2 层。
- 知识炼成的呼吸动画只在活动阶段运行，离开阶段停止并在 `dispose` 中释放。
- 试卷正文不使用实时大面积玻璃模糊。
- Motion Lab 使用静态 Fake 数据，不产生网络、模型或支付负载。

## 3. 自动化验证

- 性能策略单元测试覆盖三档行为。
- 减少动态下知识炼成、试卷装订和答案层可完成渲染。
- 真实题量未返回时不创建动态题目卡，避免无意义重绘和虚假状态。
- 完整 Flutter 测试：85 项通过。
- FastAPI 后端：19 项通过。
- Analyze：0 错误、0 警告，33 条历史 info。
- Release APK 构建成功；本轮未增加视频、大型纹理或外部动效引擎。

## 4. 模拟器验证

- 设备：Android API 36 x86_64 模拟器。
- 版本：`3.0.0+58`。
- 覆盖安装：成功，旧本地数据保留。
- 冷启动：5.837 s（模拟器一次样本，不代表真机）。
- Motion Lab：知识炼成、AI 模式传送门、试卷装订可见并可交互；入口标识为 INTERNAL。
- Logcat：未发现 Fatal Exception、ANR、OOM 或 `E/flutter`。
- 运行时内存单次样本：TOTAL PSS 约 166 MiB，TOTAL RSS 约 236 MiB。
- APK：103.64 MiB；相比 Phase 3 Dev001 的 101.67 MiB 约增加 1.97 MiB，其中禁用图标 tree shaking 用于修复 Release 中 Material 图标缺失。

`dumpsys gfxinfo` 对该 Flutter Surface 未给出稳定、可重复的帧样本，因此本轮不用模拟器数据宣称 60fps。

模拟器结果不等同真机帧率结论。

## 5. 真机待测

至少 2–3 部不同品牌、Android 版本、屏幕尺寸和性能等级的设备，检查：

- AI 模式传送门连续切换 10 次。
- 20 题知识炼成、取消、断网和失败重试。
- 试卷装订、多页预览、单题编辑和拖动排序。
- 中文/英文、浅色/深色、字体 1.3 倍、减少动态。
- OCR、TTS、PDF、后台/锁屏恢复、20 轮连续页面切换。
- `dumpsys gfxinfo`、Logcat、内存、发热、ANR 与 OOM。

在真机数据完成前，本报告不宣称达到稳定 60fps。
